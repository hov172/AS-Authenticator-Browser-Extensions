# AS Authenticator Vault support

AS Authenticator Vault is the native two-factor code app for iPhone, iPad and Mac by Ayala Solutions. The browser extension of the same name is documented in the [user guide](https://hov172.github.io/AS-Authenticator-Browser-Extensions/docs/USER-GUIDE).

## Get help

- Email: [ayala.solutions@gmail.com](mailto:ayala.solutions@gmail.com)
- Or [open an issue](https://github.com/hov172/AS-Authenticator-Browser-Extensions/issues) on GitHub.

Please say which device and version you use (Settings shows the version) and what you expected to happen. Never send a vault file, a master password, a recovery code or a QR code; nobody needs them to help you.

## Common questions

**I forgot my master password.** Use the recovery code the app showed you when you created the vault: Lock screen > Forgot password. Without the recovery code the vault cannot be opened; there is no server copy to reset it from.

**Codes are wrong.** Codes depend on the device clock. Check that Date & Time is set automatically in system settings, or turn on "Check the clock" in the app's Settings.

**Moving to a new device.** Backup > Export on the old device, then Backup > Import on the new one. The same file opens in the browser extension.

**AutoFill does not offer codes on iPhone.** Open the app once, unlock it with Face ID or Touch ID, then enable it under Settings > General > AutoFill & Passwords.
